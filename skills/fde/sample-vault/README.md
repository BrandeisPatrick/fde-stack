# Sample vault

Everything in this vault is made up: the companies, the people, the repos, the cloud projects and the URLs. It ships with the `fde` skill so the vault views (`progress`, `context`, `timeline`, `project`, `architecture`) have something to show before you set up your own vault with `/fde initialize`. The skill only reads it, never writes to it.

It is laid out the way [vault-layout.md](../references/vault-layout.md) describes.
