## 1.1.0 · 2026-11-20

- `/fde initialize`: a local vault with no remote works everywhere; workstreams are drafted or asked for on a new project; fewer repeated questions.
- The skill's description now says when to use it, so it triggers on plain requests such as "catch me up".
- Shorter README with a quick start and a command table.

## 1.0.0 · 2026-11-20

First public release.

- `/fde` session start, and the `progress`, `timeline`, `context`, `project`, `architecture`, `visual`, `recap` and `initialize` modes.
- A bundled sample vault, so the views work before any setup.
- `/fde initialize` writes your settings and sets up one project per run.
- Installable as a Claude Code plugin.
- A plan check before GitHub Pages is enabled, so a story page is never published publicly by accident.
